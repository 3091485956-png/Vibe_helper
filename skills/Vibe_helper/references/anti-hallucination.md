# 证据分级与幻觉显性化纪律

适用于一切包含事实论断的产出物：竞品调研、用户声音挖掘，以及全流程中的所有调研类环节。

**先承认现实：幻觉不可能降到零。** 本纪律的目标不是"零幻觉"。承诺不可能之事只会教人作假，把推测伪装成推断来满足规则。目标是两件做得到的事：**缓解**，用流程减少猜测；**显性化**，让每条猜测无处躲藏、可被核实。**猜测本身不是违规；把猜测藏起来、装扮成事实，才是最严重违规，发现即该段作废重做。**

## 证据三级标注：每条关键论断必须标 A / B / C

写进文档的每一条事实性论断，含竞品数据、用户抱怨、市场判断，必须三选一标注：

- **A · 有证据**：本轮真实打开过链接、亲眼核对过页面，证据本体如链接、当场核对的数字直接附上
- **B · 由证据推断**：由若干条 A 级推出，**必须同时给出证据和推理链**，即从哪几条 A、经什么逻辑得出。只贴 B 标签不写推理过程视同 C 级
- **C · 模型推测**：证据不足，来源是模型自己的判断，必须显式标注"模型推测"，并附"怎么验证它"

坏例："Notion 类工具市场竞争激烈"。谁说的？看过什么？无标注即违规。

好例："Notion 类工具市场竞争激烈 [A：头部 3 个产品官网 changelog 均迭代 5 年以上、周更]"

好例："近年无新玩家入局 [B：① 官网 changelog 显示 5 个头部位竞品最近大版本均在 3 年前，A 级；② Product Hunt 该品类搜索翻 3 页无近两年新上榜，A 级；推理：头部停滞加新品缺位，赛道冷却]"

## 信心洗白禁令

模型的自信不是证据。**决策面板里的推荐，主要依据若含 C 级论断，必须自己声明**，例如"此推荐依赖模型推测，C 级"。证据层薄薄三条、结论层语气笃定，用模型的自信给猜测洗白，是 AI 简报最经典的骗术，明令禁止。

## C 级配额与去向

- 全文 C 级条目不超过总论断数的三分之一，防偷懒：全靠猜就别叫调研
- **每条 C 级必须进文末"待核实清单"**，附验证路径，即去哪个渠道、查什么、能否升级成 A 或 B。显性化的终点是核实任务，不是免责声明。每条推测要么被核实升级，要么被淘汰

## 待核实清单，每份调研类文档末尾必有，取代旧版"本轮盲区"

一个出口收两类东西：**盲区**即没查到的，与**推测**即查了但没证据的：

```markdown
## 待核实清单
- [盲区] 未覆盖的渠道/关键词：…。要补去哪
- [盲区] 证据最薄的结论：…。加固去哪
- [推测] <C 级论断> → 验证路径：<去哪、查什么>
```

## 链接纪律

- 所有链接必须是本轮实际访问过的 URL；搜索结果里的链接，没点开看过内容就不许引用
- 禁止凭记忆拼 URL，禁止"应该存在"的链接
- 打不开的来源写"本轮无法访问，未纳入证据"

## 数据纪律

- stars、价格、评论数、发布时间等数字，只写页面上当前可见的值，不许凭印象填
- 取不到就写"未获取"。空着比编一个强

## 引用纪律

- 禁止编造用户原话、评论、帖子标题
- 搜不到就写"本轮未覆盖，建议补充 X 渠道"，这本身是有价值的结论
- 转述用户观点时区分：他们的**抱怨**是事实，他们的**建议**是意见。用户常提出错误的解决方案，抱怨才是可靠的，建议只是线索

## 溯源抽查，落盘前的最后一道

文档落盘前，从文中所有 A 级链接里**随机抽 5 个重新打开**：内容还在、数字没抄错、转述没走样。抽中一个不符则全文 A 级重新核对，不是只改那一条。一次失守说明整轮的"亲眼看过"不可信。

## 反自嗨：语气与结论强度

- **禁止自我评价**：产出物里不许出现"全面、深入、完善、详尽"这类自评词。报告好不好由用户判断
- **结论强度匹配证据**：只有 1 个来源支撑的观点，措辞必须是"初步迹象"或"待验证"，不许写成定论
- **汇报用事实句式**：说"找到 14 个同类项目，3 个近半年仍在更新"，不说"该赛道生态丰富、潜力巨大"
- **不堆砌显得勤奋**：没人问的"增值"内容不写。堆 30 个只看过搜索摘要的竞品，不如写透 10 个真打开过的
- **不确定就说不确定**：宁可承认"我没查到"，不可用流畅的废话盖住没查到

## 判断层与证据层的分界，文档双阅读模式

每份文档第一屏是**决策面板**即判断层，其后是正文即证据层：

- **克制管判断层**：面板里的推荐要少，≤3 件待判断的事，每件直给选项与依据等级
- **全面管证据层**：真打开看过的证据完整记录，给用户核实留足原料。"全面"指核实过的材料的完整记录，不是搜索摘要的堆砌
- 快速档可以砍竞品数量与渠道数，**不可以砍证据标注**。最没有能力识破幻觉的用户，恰恰最需要标注

## 判断权归用户

- agent 给出的是**建议加理由加备选**，不是决定。方向性判断如做不做、对标谁、砍哪个功能，把选项摆开让用户拍板
- 用户问"你觉得呢"可以给明确推荐，但要说明基于什么证据、还差什么证据
- 用户委托即"你定"不豁免本纪律：委托决策按 B 或 C 级留痕，规则见 SKILL.md 决策模式一节。委托不降低诚实度，只改变信任标记

## 阶段收尾自查

每个调研类产出落盘前，逐条过一遍：

1. 文中每条 A 级的链接，本轮真的打开过吗？溯源抽查 5 个跑了吗？
2. 有没有任何数字是凭印象写的？
3. 有没有无标注的事实论断？B 级都带推理链吗？
4. C 级是否不超过三分之一，且全部进了待核实清单？
5. 删掉所有自嗨句式后，文档信息量还成立吗？不成立的段落重写
