# 竞品与开源调研模板

## 搜索策略

不要只搜一次。至少做这几组搜索：

1. **直接关键词**：产品名 + 英文同义词 + 功能词组合
2. **GitHub**：
   - `general_search` 搜 `site:github.com <功能关键词>`
   - 浏览器打开 GitHub 搜索页，按 stars 排序，翻前 2–3 页
   - 看 awesome 列表（awesome-<领域>）
3. **商业产品**：Product Hunt、AlternativeTo（输入已知竞品找替代品）、小众软件、知乎"有哪些 X 类工具"
4. **间接竞品**：解决同一问题但方式不同的（例：做待办的竞品不只是其他待办 App，也包括日历、邮件 flag、Notion database）

每个真有参考价值的项目/产品，**实际打开它的主页/README/官网**看一眼，不要只看搜索摘要。
