# 零幻觉与反自嗨纪律

适用于所有调研类阶段（Stage 3、4）以及一切包含事实论断的产出物。**编造链接、数据、用户原话是最严重违规，发现即该段作废重做。**

## 事实分级：每条关键论断必须标注来源等级

写进文档的每一条事实性论断（竞品数据、用户抱怨、市场判断），必须三选一标注：

- **[实证]** 有链接，且本轮真实打开过该页面、亲眼看到
- **[推断]** 由若干 [实证] 合理推出（写清从哪些实证推出）
- **[假设]** 未验证的猜测——必须显式标出，且全文 [假设] 条目不得超过三分之一

不允许出现无标注的事实论断。"很多用户抱怨 X"没有出处 = 违规。

## 链接纪律

- 所有链接必须是本轮实际访问过的 URL；搜索结果里的链接，没点开看过内容就不许引用
- 禁止凭记忆拼 URL，禁止"应该存在"的链接
- 打不开的来源写"（本轮无法访问，未纳入证据）"

## 数据纪律

- stars、价格、评论数、发布时间等数字，只写页面上当前可见的值，不许凭印象填
- 取不到就写"未获取"——空着比编一个强

## 引用纪律

- 禁止编造用户原话、评论、帖子标题
- 搜不到就写"本轮未覆盖，建议补充 X 渠道"——这本身是有价值的结论
- 转述用户观点时区分：他们的**抱怨**（事实）和他们的**建议**（意见）

## 反自嗨：语气与结论强度

- **禁止自我评价**：产出物里不许出现"全面、深入、完善、详尽"这类自评词。报告好不好由用户判断
- **结论强度匹配证据**：只有 1 个来源支撑的观点，措辞必须是"初步迹象 / 待验证"，不许写成定论
- **主动暴露盲区**：每份调研类文档末尾必须有"本轮盲区"小节——没查到什么、哪些结论最脆弱、要加固该去哪补
- **汇报用事实句式**：说"找到 14 个同类项目，3 个近半年仍在更新"，不说"该赛道生态丰富、潜力巨大"
- **不堆砌显得勤奋**：没人问的"增值"内容不写，产出物每个部分都应对应某个用户决策
- **不确定就说不确定**：宁可承认"我没查到"，不可用流畅的废话盖住没查到

## 判断权归用户

- agent 给出的是**建议 + 理由 + 备选**，不是决定。方向性判断（做不做、对标谁、砍哪个功能），把选项摆开让用户拍板
- 用户问"你觉得呢"可以给明确推荐，但要说明基于什么证据、还差什么证据

## 阶段收尾自查

每个调研类阶段落盘前，逐条过一遍：

1. 文中每条 [实证] 的链接，本轮真的打开过吗？
2. 有没有任何数字是凭印象写的？
3. 有没有无标注的事实论断？
4. 删掉所有自嗨句式后，文档信息量还成立吗？不成立的段落重写
